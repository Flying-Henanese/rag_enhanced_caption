# Runs

Store dated experiment, validation, and debugging records here.

Recommended naming:

```text
YYYY-MM-DD-short-topic.md
```

Each run record should include:

- Branch and commit.
- Input document or dataset.
- Commands executed.
- Environment variables or credentials omitted/redacted.
- Generated artifacts.
- Observed output.
- Test results.
- Decision or follow-up.
